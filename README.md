# Portal 2 Takeover

**skatebird** × Portal 2 · visual · idea by the team

Bring Portal 2 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned SkateBIRD into a Portal 2 test chamber: portals, a companion cube, gel and angry turrets. The cube bowling the turrets was my favorite part.

## Install

Copy the release folder's BepInEx folder into your SkateBIRD folder (BepInEx 5 must be installed), then start the game. Press Q for a blue portal and E for an orange one, ride through, smash the turrets and grab the cake.
